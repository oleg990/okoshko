# okoshko

Сервис онлайн-записи к мастерам-одиночкам (ресницы, маникюр, барберы). Мастер получает публичную страницу с услугами и свободным временем, клиент записывается без регистрации, а подтверждения и напоминания приходят в Telegram.

> Статус: в разработке. Сейчас идёт этап 0 (каркас проекта).

## Зачем

Мастера ведут запись вручную в мессенджерах: забывают, путают время, клиенты не приходят. Okoshko показывает только свободное время, не даёт записать двух клиентов на одно окно и сам напоминает о визите.

## Возможности MVP

- Вход мастера через Telegram, без паролей.
- Профиль мастера с публичной ссылкой `/m/<slug>`.
- Услуги с длительностью, буфером между клиентами и ценой.
- Недельное расписание, выходные и больничные.
- Расчёт свободного времени с учётом часового пояса мастера.
- Запись клиента по имени и телефону, управление записью по секретной ссылке.
- Подтверждение или отклонение записи мастером (или автоподтверждение).
- Напоминания клиенту за сутки и за 2 часа.
- Защита от двойной записи на уровне PostgreSQL.

Что войдёт позже и что сознательно не делаем, описано в [docs/mvp.md](docs/mvp.md).

## Технологии

Go, PostgreSQL, pgx, Docker Compose, GitHub Actions, Telegram Bot API.

## Быстрый старт

Нужны Go и Docker.

```bash
cp .env.example .env
docker compose up -d
```

Команда запуска API появится после этапа 0.
